# Amazon Simple Storage Service S3 Interview Questions & Answers

## 1. What is S3?

S3 (Simple Storage Service) is AWS object storage service used to store files, images, videos, backups, logs, etc.

---

## 2. What are the main features of S3?

* Highly scalable
* Durable (11 9’s durability)
* Highly available
* Secure
* Versioning support
* Lifecycle management

---

## 3. What is an S3 Bucket?

Bucket is a container used to store objects/files in S3.

Example:

```txt id="1"
my-app-images
```

---

## 4. What is an Object in S3?

Object = File + Metadata + Unique Key

Example:

```txt id="2"
profile.png
```

---

## 5. What is the maximum size of an S3 object?

* Single upload → 5 GB
* Multipart upload → 5 TB

---

## 6. What is Multipart Upload?

Large file uploaded in parts/chunks.

Benefits:

* Faster uploads
* Retry failed parts only
* Better for large files

---

## 7. What are S3 Storage Classes?

| Storage Class              | Use Case                  |
| -------------------------- | ------------------------- |
| Standard                   | Frequently accessed data  |
| Standard-IA                | Infrequent access         |
| One Zone-IA                | Low-cost single AZ        |
| Glacier Instant Retrieval  | Archived but quick access |
| Glacier Flexible Retrieval | Long-term archive         |
| Glacier Deep Archive       | Cheapest archival storage |

---

## 8. What is Versioning in S3?

Keeps multiple versions of same file.

Useful for:

* accidental deletion recovery
* rollback
* audit

---

## 9. What is Lifecycle Policy?

Automatically moves or deletes objects based on rules.

Example:

* Move to Glacier after 30 days
* Delete after 1 year

---

## 10. Difference between Versioning and Lifecycle?

| Versioning               | Lifecycle          |
| ------------------------ | ------------------ |
| Stores multiple versions | Manages object age |
| Recovery feature         | Cost optimization  |

---

## 11. What is S3 Durability?

S3 provides:

```txt id="3"
99.999999999% durability
```

Data replicated across multiple AZs.

---

## 12. Difference between Durability and Availability?

| Durability              | Availability       |
| ----------------------- | ------------------ |
| Data not lost           | Service accessible |
| Focus on storage safety | Focus on uptime    |

---

## 13. What is Pre-Signed URL?

Temporary secure URL generated to upload/download private objects.

Useful when:

* frontend uploads directly to S3
* temporary file sharing

---

## 14. What is Static Website Hosting in S3?

S3 can host:

* HTML
* CSS
* JS websites

Usually combined with:

* Amazon CloudFront
* Amazon Route 53

---

## 15. Can S3 run backend code?

No. S3 is storage only.

Dynamic backend requires:

* EC2
* Lambda
* ECS etc.

---

## 16. What is S3 Event Notification?

Triggers actions when events occur.

Example:

* file upload
* delete

Can trigger:

* Lambda
* SQS
* SNS

---

## 17. What is Cross-Region Replication (CRR)?

Automatically copies objects to another AWS region.

Used for:

* disaster recovery
* global access

---

## 18. What is Same-Region Replication (SRR)?

Replicates data within same region.

Useful for:

* compliance
* log aggregation

---

## 19. Difference between CRR and SRR?

| CRR              | SRR                  |
| ---------------- | -------------------- |
| Different region | Same region          |
| DR use case      | Internal replication |

---

## 20. What is Transfer Acceleration?

Uses AWS edge network to speed up uploads globally.

---

## 21. What is Bucket Policy?

JSON-based access control policy attached to bucket.

Controls:

* who can access
* what actions allowed

---

## 22. Difference between IAM Policy and Bucket Policy?

| IAM Policy              | Bucket Policy      |
| ----------------------- | ------------------ |
| Attached to users/roles | Attached to bucket |
| Identity-based          | Resource-based     |

---

## 23. What is Block Public Access?

Security feature preventing accidental public exposure of bucket/files.

Very important in production.

---

## 24. What is S3 Encryption?

Types:

* SSE-S3
* SSE-KMS
* SSE-C
* Client-side encryption

---

## 25. Difference between SSE-S3 and SSE-KMS?

| SSE-S3           | SSE-KMS                            |
| ---------------- | ---------------------------------- |
| AWS manages keys | KMS manages keys                   |
| Basic encryption | Advanced access control & auditing |

---

## 26. What is Eventual Consistency?

Older concept where object updates may take time to reflect.

Now S3 provides strong read-after-write consistency.

---

## 27. Can S3 be mounted like a traditional filesystem?

Not directly. S3 is object storage, not block/file storage.

---

## 28. Difference between S3, EBS, and EFS?

| S3                  | EBS             | EFS                |
| ------------------- | --------------- | ------------------ |
| Object storage      | Block storage   | File storage       |
| Unlimited scale     | Attached to EC2 | Shared filesystem  |
| Internet accessible | Single instance | Multiple instances |

---

## 29. Scenario:

How would you securely upload files from frontend to S3?

Answer:

* Backend generates pre-signed URL
* Frontend uploads directly to S3
* Avoids backend load

---

## 30. Scenario:

How do companies serve images globally from S3?

Answer:
Use:

* S3 bucket as origin
* CloudFront CDN
* Route 53 custom domain

---

## 31. Scenario:

How to reduce S3 storage cost?

Answer:

* Lifecycle policies
* Glacier storage classes
* Delete unused objects
* Compression

---

## 32. Scenario:

How to recover accidentally deleted files?

Answer:
Enable:

* Versioning
* MFA delete (optional)

---

## 33. Scenario:

How do you protect sensitive S3 data?

Answer:

* IAM policies
* Bucket policies
* Encryption
* Block public access
* Private buckets
* CloudFront signed URLs/cookies












Question: Tell me Usecase of AWS S3 Express One Zone ?
Ans:Amazon S3 Express One Zone is used when applications need **very fast access latency and high request performance** from S3.

## Main Use Cases

* **AI/ML workloads**
  Fast access to training datasets and model data.

* **Real-time analytics**
  Applications reading/writing huge data quickly.

* **Media rendering & video processing**
  High-speed parallel object access.

* **High-performance computing (HPC)**
  Low-latency storage access for compute-intensive workloads.

* **Frequent small object access**
  Better performance than normal S3 for very high request rates.

---

## Why Companies Use It

Normal S3 is highly scalable but optimized for general storage.

S3 Express One Zone provides:

* single-digit millisecond latency
* very high throughput
* faster object access

---

## Important Point

It stores data in **single Availability Zone**, so:

* performance is very high
* cost may be lower
* but durability scope is lower than multi-AZ S3 Standard

So it is mainly used for:

> performance-critical workloads, not long-term critical backups.












Question: What is S3 Requester Pay?
Ans:
Amazon Simple Storage Service Requester Pays is an S3 feature where the **person downloading/accessing the data pays the request and data transfer cost instead of the bucket owner**.

---

## Normal S3 Billing

Normally:

* Bucket owner pays for:

  * storage
  * requests
  * download bandwidth

---

## In Requester Pays

Requester pays for:

* GET requests
* download charges
* data transfer

Bucket owner still pays for:

* storage cost

---

## Use Case

Useful when:

* sharing large public datasets
* many external users access files
* bucket owner doesn't want to pay transfer costs

Example:

* research datasets
* public analytics data
* government open data

---

## Important Point

Requester must:

* use AWS credentials
* explicitly specify requester pays in request

Otherwise access fails.

---

## Interview One-Line Answer

> S3 Requester Pays is a billing feature where the requester accessing/downloading objects pays the request and data transfer charges instead of the bucket owner.
